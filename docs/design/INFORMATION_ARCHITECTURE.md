# Information architecture

- **Library** opens Songs and Setlists. Search, favorites, sorting, import, and creation belong to this surface.
- **Song** opens the score. The toolbar leads to edit, add to setlist, export, print, delete, and performance.
- **Song details** contains pitch, zoom, annotation controls and metadata for the selected song.
- **Setlist** contains ordered song appearances. Each appearance can keep pitch and capo overrides. The performance toolbar shows the current position when a set entry is active.
- **Settings** contains appearance preferences and backup operations. Restore opens a separate preview with record counts, warnings and the transaction mode.
