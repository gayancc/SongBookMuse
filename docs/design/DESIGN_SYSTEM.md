# Design system

**Visual thesis.** A dim, matte rehearsal workspace surrounds a warm sheet with the contrast and quiet hierarchy of printed session music.

**Content plan.** The library provides songs and setlists. The active sheet is the visual anchor. Song details hold pitch, zoom and annotations. Performance mode centers the sheet and keeps navigation within reach.

**Interaction thesis.** Short hover and press transitions signal controls. The details drawer and action menu appear with a subtle reveal. Scrolling remains native, and performance tools stay visible while the sheet moves. Reduced-motion users receive immediate transitions.

| Role | Choice |
| --- | --- |
| UI text | DM Sans Variable, locally packaged |
| Chart title | DM Serif Text, locally packaged |
| Shell | Charcoal green surfaces and one pale chartreuse accent |
| Sheet | Warm paper, dark lyrics, olive chords |
| Light shell | Warm neutral backgrounds with dark accent |
| Stage contrast | Black, white and yellow-green chord emphasis |
| Controls | Semantic buttons and inputs. Compact desktop targets and 44 px phone controls where rendered in navigation and toolbars. |
| Icons | Lucide with names on icon-only controls. |
