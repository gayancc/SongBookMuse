# Responsive layouts

| CSS viewport | Layout |
| --- | --- |
| Above 1,180 px | Transport with full LCD, browser 288 px, sheet, optional 272 px inspector, hint bar. |
| 1,051–1,180 px | LCD hides BPM and meter cells; brand text hides. |
| 661–1,050 px | Browser 250 px; Import becomes icon-only; inspector overlays from the right. |
| At most 660 px | One task at a time with bottom tabs. Transport keeps import, song navigation, LCD title and set position, and settings. Hint bar hides. |
| Performance | Sheet spans the viewport with a 52 px stage bar. |

Verified at 1360×820, 900×700 and 390×730 CSS pixels in the Windows WebView2 suite. Native tablet and phone orientation remain unverified.
