# Accessibility

- Native HTML controls provide names, focus, activation and disabled states. Icon-only controls include explicit names.
- The score preserves lyric and chord text in the DOM for zoom and selection. Canvas pages have an accessible page label. PDF text extraction and accessible fixed-document reading are open.
- Record operations expose status and alerts. Modal dialogs have a heading and use native focus trapping.
- Contrast mode uses near-black surfaces, white text and yellow-green chords. The shell respects reduced motion. Touch navigation uses a one-task layout on compact widths.
- Keyboard, UI focus and responsive viewport tests cover ordinary controls. Screen-reader runs, physical switch control, stylus accessibility and OS text-size scaling are still open.
