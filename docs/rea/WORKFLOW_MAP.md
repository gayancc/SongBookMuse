# Workflow map

| Task | Reference entry and flow | Muse workflow |
| --- | --- | --- |
| Find a song | Songs → All Songs → search, order or filter → select a row. E02, E10. | Library → query or Favorites → select a row. |
| Write a chart | Songs → add → create → fill editor → save. E02–E03. | Library → New song → source and live preview → Save song. |
| Import files | Songs → add → import files → select files. Camera and online options have separate paths. E02. | Import or drop files on the library. Rust validates the full batch before a single write transaction. |
| Rehearse a set | Sets → select or create set → add songs in order → tap first item → page or song navigation. E04. | Setlists → new/edit set. From a song use Song actions → Add to setlist. Select set entry, reorder with arrows, then Perform. |
| Tune song display | Command bar → Quick Actions → key, capo and display controls. E05. | Song details → Transpose/Capo, Zoom. Lyrics-only and columns live in the viewer toolbar. |
| Mark up fixed page | Live Buttons → drawing button → draw and save. Reference toolbar entry documented in E05. | Song details → Draw on page → mouse, touch or pen input. Each finished stroke persists to the song and page. Undo/redo applies individual strokes. |
| Protect library | Settings → Backup & Sync → Backup library or Restore library. E07, E10. | Settings → Export backup or Restore backup → preview → merge or replace. |
| Share group material | Groups account/organization → library selection → shared song/set actions subject to role. E08. | Open. |
